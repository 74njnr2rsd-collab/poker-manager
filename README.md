# Poker Manager — первая рабочая версия

## Что умеет
- Начало и завершение покерной сессии.
- Неограниченные докупы и выходы.
- Текущая статистика игроков.
- Проверка общего баланса.
- Расчёт переводов между проигравшими и победителями, если баланс сессии сходится.
- История завершённых игр.
- Общая статистика и рейтинг.
- Профили игроков.
- Отмена и изменение собственной операции.
- SQLite хранит данные между перезапусками.

## 1. Создание Telegram-бота
1. Откройте в Telegram `@BotFather`.
2. Выполните `/newbot` и следуйте инструкциям.
3. Скопируйте токен.
4. Скопируйте `.env.example` в `.env` и вставьте токен в `BOT_TOKEN`.

## 2. Настройка группы
1. Добавьте бота в покерную группу.
2. Для чтения команд в группе обычно достаточно стандартного режима приватности.
3. Если позже понадобится чтение обычных сообщений, отключите Group Privacy у бота через BotFather.
4. Для MVP не выдавайте боту права администратора без необходимости.

## 3. Установка
Требуется Python 3.10 или новее.

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
python -m bot.main
```

## 4. Использование
Сначала каждый игрок связывает свой Telegram ID с именем:

`/join Марат`

Начать сессию:

`/start_poker`

Записать докуп:

`/buy 3000 Марат`

Записать выход:

`/exit 10000 Марат`

Показать статистику:

`/stats`

Завершить сессию:

`/end_poker`

Другие команды: `/help`, `/players`, `/history`, `/total`, `/player Марат`, `/leaderboard`.

Операции можно исправлять по ID, который бот показывает после записи:

`/edit 12 5000`

`/cancel 12`

## Важные ограничения первой версии
- В этой версии SQLite — для запуска на одном сервере и в одной небольшой группе.
- Операции можно отменять/исправлять только автору операции. Админское управление чужими операциями нужно добавить отдельно в следующей итерации.
- Расчёт долгов выполняется только при нулевой разнице между суммой всех докупов и всех выходов.
- Команда `/exit` фиксирует сумму выхода; если игрок выходит частями, можно внести несколько операций.
- Игроки создаются по имени, указанному в команде. `/join Имя` связывает Telegram ID пользователя с профилем. Для строгого контроля авторизации нужно добавить отдельную проверку прав и защиту от совпадающих имён.
- Это стартовый MVP, перед реальной эксплуатацией нужно протестировать на тестовой группе и сделать резервное копирование файла базы данных.

## Рекомендуемый следующий этап
