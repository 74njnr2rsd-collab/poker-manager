# Poker Manager Telegram Bot

Telegram-бот для учёта покерных игр, бай-инов, выходов, общей статистики и расчёта переводов.

## Файлы
- `main.py` — Telegram-команды и необязательный AI-чат.
- `db.py` — SQLite-база.
- `calculations.py` — расчёт взаиморасчётов.

## Запуск
Требуется Python 3.10+.

```bash
pip install -r requirements.txt
python main.py
```

## Переменные окружения
Обязательно:
- `BOT_TOKEN` — токен Telegram-бота из BotFather.

Необязательно:
- `OPENAI_API_KEY` — ключ OpenAI API. Без него все покерные команды работают, но AI-ответов не будет.
- `OPENAI_MODEL` — по умолчанию `gpt-4o-mini`.
- `BOT_USERNAME` — имя бота без `@`; если не указано, бот узнаёт его при запуске.
- `DB_PATH` — путь к файлу SQLite. На хостинге укажи путь к постоянному диску, если он предусмотрен.

## Команды
- `/join` — зарегистрироваться в чате.
- `/players` — список игроков.
- `/start_poker` — открыть игру.
- `/buy 1000` — записать бай-ин.
- `/exit 2500` — записать выход.
- `/stats` — статистика текущей игры.
- `/end_poker` — закрыть игру и рассчитать переводы (только если сумма бай-инов равна сумме выходов).
- `/total` — общий баланс.
- `/leaderboard` — рейтинг.
- `/history` — последние операции.
- `/cancel ID` — отменить операцию.
- `/edit ID СУММА` — изменить сумму операции.
- `/player Имя` — общий результат игрока.

## Важно
1. Не загружай `.env` и токены в GitHub. Добавляй секреты в настройках хостинга.
2. Для работы в группе отключи Group Privacy у BotFather, если бот должен читать обычные сообщения. Команды бот сможет получать и без этого.
3. AI-функция использует OpenAI API и может тарифицироваться отдельно. Без `OPENAI_API_KEY` бот работает как обычный покерный бот.
4. AI отвечает на прямое упоминание/ответ боту или сообщения с покерными ключевыми словами. Есть ограничение частоты ответов.
5. SQLite-файл должен находиться на постоянном диске хостинга. Если файловая система временная, история может потеряться при пересоздании приложения.
6. Перед переносом существующей базы сделай резервную копию `poker.sqlite3`.


## Долговременная память ИИ

Бот сохраняет сообщения, ответы ИИ и долговременные заметки в SQLite. Память не ограничена 20 сообщениями и переживает перезапуск процесса, если база SQLite находится на постоянном диске.

- `RECENT_CONTEXT_MESSAGES=40` — сколько последних сообщений передавать модели как непосредственный контекст.
- `MEMORY_BATCH_SIZE=25` — после скольких новых пользовательских сообщений создавать очередную сводку.
- `MEMORY_CONTEXT_LIMIT=20` — сколько последних долговременных заметок добавлять в контекст модели.
- `DB_PATH=/data/poker.sqlite3` — путь к базе. На хостинге укажи путь на persistent volume/disk, иначе данные могут пропасть при пересоздании контейнера.

История чата хранится отдельно от краткого контекста модели: ограничение контекста не удаляет сообщения из SQLite.
